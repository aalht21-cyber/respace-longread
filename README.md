# Анатомия комнаты — ReSpace

Лонгрид о маленьком жилье и знакомство с ReSpace — цифровым помощником, который превращает маленькую квартиру в удобное жильё под образ жизни человека.

Вечер в студии 25 м²: хозяйка ставит чайник и по ходу показывает дом — от ночного фасада до окна с лампой. Одиннадцать экранов, режим «Уют / Чертёж», сцены, которые движутся вместе с прокруткой.

## Как открыть

Сайт статический: HTML, CSS и JavaScript без сборки. Локально его можно открыть через любой простой сервер, например:

```
python3 -m http.server 8000
```

и перейти на `http://localhost:8000/`.
